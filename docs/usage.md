# Guia de Uso — Smart Terminal AI Search

## Início Rápido

1. Execute `python main.py`
2. Digite sua pergunta
3. Aguarde o processamento
4. Leia a resposta e explore os links

## Comandos Avançados

### Cache
- O cache evita pesquisas repetidas
- TTL padrão: 24 horas
- Use `/cache` para ver estatísticas

### Histórico
- Todas as pesquisas são salvas automaticamente
- Use `/historico` para visualizar
- Use `/limpar` para apagar tudo

### Configurações
- Edite `settings.json` para personalizar
- Reinicie o programa após alterações

## Dicas

- Seja específico nas perguntas
- Use termos técnicos para melhores resultados
- O modo detalhado mostra mais informações
